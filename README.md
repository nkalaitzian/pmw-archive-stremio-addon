## A Stremio extension to stream content from archive.wubby.tv

Resources:
- https://www.stremio.com/addon-sdk
- https://github.com/Stremio/stremio-addon-sdk/blob/master/README.md
- https://github.com/Stremio/stremio-addon-sdk/blob/master/docs/testing.md#testing-in-stremio-app
- https://staging.strem.io/#/
- https://archive.wubby.tv/vods/public/may_2025/?C=M&O=A

Commands:

`npm install`

`npm start -- --launch`

`$env:DEBUG_PMW='true'; npm start -- --launch`

`npm start -- --install`

`npm test`

Behavior:
- `PMW Archive` catalog lists one series per year.
- Opening a year lazily loads month episodes for that year.
- `PMW Recently Added` catalog includes the latest 20 episodes by stream date.

Per-user settings (in Stremio):
- Open the addon page and click `Configure`.
- You can set:
	- `recentLimit`: how many items appear in `PMW Recently Added` for your install.
	- `yearSort`: ascending or descending year order.
	- `cleanTitles`: show cleaned titles or raw filenames.
	- `cacheMode`: one preset for caching behavior (`fresh`, `balanced`, `stable`).
		- `fresh`: index cache 30m, month cache 120m, recent cache 5m, scans latest 6 months for recent rebuilds.
		- `balanced`: uses server defaults (index 6h, month 24h, recent 15m, latest 2 months scanned by default).
		- `stable`: index cache 12h, month cache 48h, recent cache 60m, scans latest 2 months.
	- Caching parameter glossary:
		- `indexTtlMs`: validity window for the month/year index cache before refresh.
		- `monthTtlMs`: validity window for each cached month payload before refresh.
		- `recentTtlMs`: validity window for the `PMW Recently Added` cache before refresh.
		- `recentMonthsToRefresh`: number of newest months scanned when rebuilding the recent list.
- These are user-specific and do not affect other users.

Configure page:
- Local: `http://127.0.0.1:7000/configure`
- The SDK serves this page automatically when `manifest.config` is set.
- Configured installs use a config-prefixed manifest URL (JSON-encoded path segment), generated by the SDK configure UI.
- Custom text on this page comes from `manifest.description` and each `manifest.config[].title` in `addon.js`.
- Support links shown on this page are controlled in `addon.js` via `ARCHIVE_URL`, `REPO_URL`, `ISSUES_URL` and `DONATE_URL`.

Configuration (all optional):
- `PMW_RECENT_LIMIT` (default `20`)
- `PMW_REFRESH_INTERVAL_MS` (default `1800000`)
- `PMW_RECENT_MONTHS_TO_REFRESH` (default `2`)
- `PMW_INDEX_TTL_MS` (default `21600000`)
- `PMW_MONTH_TTL_MS` (default `86400000`)
- `PMW_RECENT_TTL_MS` (default `900000`)
- `PMW_HTTP_TIMEOUT_MS` (default `10000`)
- `PMW_HTTP_RETRIES` (default `2`)
- `PMW_HTTP_RETRY_DELAY_MS` (default `300`)
- `PMW_HTTP_MAX_CONCURRENT_REQUESTS` (default `1`)
- `PMW_HTTP_MIN_INTERVAL_MS` (default `500`)
- `PUBLISH_CENTRAL=true` to publish to Stremio Central on start
- `DEBUG_PMW=true` to enable debug mode
- `PMW_DIAGNOSTICS_PORT` (default `7001`) for diagnostics endpoint

Production safety tip:
- Set `PMW_REFRESH_INTERVAL_MS=0` to disable scheduled background refresh.
- Keep `PMW_HTTP_MAX_CONCURRENT_REQUESTS=1` and raise `PMW_HTTP_MIN_INTERVAL_MS` (for example `1000`) to reduce third-party request rate.

Diagnostics (when `DEBUG_PMW=true`):
- `http://127.0.0.1:7001/health`
- `http://127.0.0.1:7001/diagnostics`
